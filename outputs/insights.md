# Key Insights — Dhaka Weather Data Analysis

> This project uses synthetic practice data generated with NumPy, modelled on Dhaka's seasonal patterns. The findings below are for learning the workflow only; they are not real weather records.

- Dataset size: **365 days** (1 January – 31 December 2025).
- Hottest month by average temperature: **May** (31.39 °C).
- Wettest month by total rainfall: **July** (617.42 mm).
- Worst air quality month by average AQI: **January** (average AQI 194.98).
- Correlation between humidity and temperature: **0.11**.
- Hottest single day: **2025-05-20** at 36.68 °C.
- Rainiest single day: **2025-06-16** with 80.00 mm of rain.
- Total rainfall for the year: **2012.56 mm**; rainy days (rainfall > 0): **113**.
